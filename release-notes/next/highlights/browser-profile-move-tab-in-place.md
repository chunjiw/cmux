title: Move a tab to another browser profile without losing its place
category: new
action: browserProfile.moveTab | Try it

Move Tab to Browser Profile now keeps the tab: same place, same tab, and the page reloads at the same address in the new profile, with that profile's cookies, site data and permissions. Back and forward history starts over in the new profile. Agents can do the same from the command line with `cmux browser-profile move-tab`.
